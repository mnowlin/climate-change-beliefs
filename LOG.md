## Project Overview

An examination of the climate change belief system as a network, incorporating cultural worldviews (cultural theory), political ideology, partisanship, environmental orientation (NEP scale), perceived scientific consensus, and climate policy preferences into a single Gaussian graphical model (GGM). Uses original quota-based US survey data (SSI, October 2017, N = 1,409) to identify which beliefs are most central via betweenness, closeness, and strength centrality, testing three competing hypotheses (deep core beliefs, scientific consensus as gateway belief, policy/secondary beliefs).

**Key files:**
- `manuscript/climate-beliefs.qmd` — main manuscript (renders to HTML, PDF, DOCX); contains the primary GGM estimation and centrality analysis inline
- `scripts/create-dataset.R` — builds `data/beliefDataRep.csv` from the raw `data/nationalData.csv`
- `scripts/centrality-measures.R` — standalone version of the manuscript's network/bootstrap analysis; produces `data/network_data_for_replication.RData` (loaded by the qmd) and `manuscript/centralPlots.png`
- `scripts/climate_ggm.R` — extended/companion GGM analysis (robustness checks, CV-LASSO, pairwise difference tests) written for the reviewer response; outputs to `outputs/`
- `scripts/bayes-net.R` — Bayesian network robustness check as a companion to the GGM (loads `data/ggm_centrality_table.csv` for the GGM-vs-BN comparison table)
- `scripts/high-low-egal-graphs.R` — subgroup (low/high egalitarian, low/high risk) centrality comparison; currently **not reproducible standalone** — depends on `data/network_data_for_replication2.RData` / `...3.RData`, which aren't present in `data/`
- `scripts/export-cited-refs.R` — pre-render step that trims the master `.bib` to cited keys and copies the CSL into `manuscript/`
- `reviews/` — R&R materials: decision letter, extracted review text, and a response-to-reviewers plan
- `README.md` — project structure and reproduction instructions

## Key Analytical Decisions

- **Network model**: Gaussian graphical model (GGM) via `bootnet`/`qgraph`, `EBICglasso` default, `cor_auto` correlation method (polychoric/polyserial as appropriate for ordinal data), tuning (EBIC gamma) = 0.5.
- **Centrality measures**: betweenness, closeness, strength, estimated via nonparametric bootstrap (1,000 resamples).
- **17 composite belief nodes**: deep core (hierarchy, egalitarianism, individualism, fatalism, ideology, partisanship, NEP scale), policy core (happening, risk, scientific consensus), secondary/policy preferences (international agreement, renewables, nuclear, carbon tax, EPA regulation, cap-and-trade, geoengineering).
- **Robustness (added for R&R)**: EBIC gamma sensitivity (0, 0.25, 0.5, 0.75, 1.0), CV-LASSO comparison via `huge`, pairwise centrality difference tests, and a Bayesian network (`bnlearn`) companion analysis for directed-structure comparison.

### Session 17 — 2026-08-04 (Walked back causal language in BN prose)

- User asked how causal the BN's directed-edge language could legitimately be, and whether "upstream" beliefs are thought to cause "downstream" ones. Answered: no — `scripts/bayes-net.R` uses hill-climbing, tabu search, and PC on purely cross-sectional observational data with no temporal ordering, experimental manipulation, or causal-identification assumptions (no LiNGAM, no background-knowledge edge constraints). Score-based algorithms (HC, Tabu) always return a *fully* directed acyclic graph even when multiple DAGs are Markov-equivalent (fit the data identically) — the chosen direction reflects the search/score criterion, not something the data distinguished from its reverse. PC can identify some orientations unambiguously via conditional-independence testing but generally leaves others unresolved without further assumptions. Flagged that several phrases in the Session 13 draft prose already overclaimed on this ("directly influence," "estimated to be more 'upstream' than," "functions as... parent belief") — exactly the kind of language R1-3/R2 already push back on for the GGM.
- Walked back that language in all three BN passages in `manuscript/climate-beliefs.qmd` (Methods, Results, Discussion): replaced "influence" framing with "occupies an upstream/'parent' *position* in the estimated graph," and added explicit parenthetical reminders that this describes estimated graph position, not demonstrated causal precedence.
- **Added a new caveat paragraph** in the Methods section (bold-in-italics, part of the existing R2-2 draft block) explaining exactly why these algorithms can't identify causal direction from cross-sectional data — Markov equivalence for score-based methods, partial identification at best for PC.
- Caught and fixed a Pandoc/CommonMark formatting bug while adding the caveat: initially placed it as a second paragraph inside the same italic (`_..._`) span as the preceding paragraph, separated by a blank line — CommonMark emphasis cannot span a paragraph break, so it would have rendered as plain (non-italic) text with stray literal underscores.
